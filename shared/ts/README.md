# Shared TypeScript packages

- `tokens`: canonical theme token schema, Light/Dark defaults, validation, CSS-variable and React Native output.
- `api-client`: generated OpenAPI types plus a small typed fetch wrapper.
- `i18n`: runtime translation loader with an in-memory cache and ETag support.
- `module-sdk`: frontend module manifest types and registry.
- `calendar`: Ethiopian calendar stub (implemented fully in P1-15).
- `money`: ETB santim helpers mirroring `shared/py/erp_shared/money.py`.
